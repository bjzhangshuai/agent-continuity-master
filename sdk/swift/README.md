# AgentContinuity Swift SDK

Swift Package for iOS 15+, iPadOS 15+, and macOS 12+. It includes the REST client, portable Ed25519 event and sync signing, X25519 device identity, Keychain identity storage, offline runtime stores, Agent binding, Continuity Package retrieval, and cursor sync.

```sh
swift run AgentContinuitySelfTest
```

Add this directory as a local Swift Package in Xcode and import `AgentContinuity`. See `docs/device-agent-sdk.zh-CN.md` for an App lifecycle example.
