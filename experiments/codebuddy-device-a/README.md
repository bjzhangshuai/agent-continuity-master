# CodeBuddy Device A local experiment

Open this directory in CodeBuddy CN and create a **new** test conversation. Only
that opted-in workspace is captured. Existing CodeBuddy conversations are not
scanned. The generated `.codebuddy/`, `.continuity/` and test results are ignored
by Git because they contain machine-specific local configuration.

Suggested test message:

> 请读取 `conversation-demo.md`，总结跨设备接续的三个验收点；不要修改其他文件。
