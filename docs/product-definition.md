# Product Definition

Agent Continuity is the persistent Task State layer between agents, devices, models, people, and organizations. A Task owns its goal, status, causal event graph, artifacts, bindings, permissions, provenance, and audit trail; conversation is one event family inside that object.

The product promise is task-level continuity. Native vendor session resume is used when a supported adapter can prove compatibility. Otherwise the platform generates a vendor-neutral rehydration package and never claims to clone private runtime state.

P0 users are multi-device AI developers and small teams. The success event is a Task being continued on a different device, agent, or by an invited participant without losing work or silently overwriting a branch.

Non-goals include generic IM, cloud-drive replacement, opaque UI scraping, and global total ordering. The five governing qualities are Persistent, Portable, Causal, Secure, and Collaborative.
