# Go-to-Market

The initial wedge is developers who already switch between coding agents or computers. The repeatable demo imports a 60%-complete Task, continues it in a second agent, lazy-loads an Artifact and invites a reviewer without copying a chat transcript.

Distribution starts with the Go CLI/daemon, open protocol schemas, adapter examples and reproducible self-hosting. Growth loops are successful resume → shared Task → invited collaborator → another adapter/device. Enterprise discovery validates audit, private deployment and data residency before broad social features.
